Android 딥링크 테스트를 위한 강력한 데스크톱 도구

✨ 주요 기능

🔗

딥링크 관리

Android 앱의 딥링크를 쉽게 생성하고 관리할 수 있습니다

📱

ADB 통합

내장된 ADB를 통해 연결된 디바이스로 즉시 딥링크를 전송합니다

📊

카테고리 분류

딥링크를 카테고리별로 정리하고 색상으로 구분할 수 있습니다

🕐

히스토리 관리

테스트한 딥링크의 전체 히스토리를 확인하고 재사용할 수 있습니다

💾

로컬 데이터베이스

Room 데이터베이스를 활용한 안정적인 데이터 저장

🎨

모던 UI

Jetpack Compose로 제작된 직관적이고 아름다운 인터페이스

Kotlin Multiplatform Jetpack Compose Room Database Koin DI Coroutines

💾 다운로드

사용하시는 Mac의 칩셋에 맞는 버전을 다운로드하세요

🖥️
Intel Mac 버전 Intel 프로세서용
💻
Apple Silicon 버전 M1/M2/M3 칩용

📋 시스템 요구사항

  • macOS 10.15 (Catalina) 이상
  • 최소 4GB RAM (8GB 권장)
  • 약 200MB의 디스크 공간
  • Android 디바이스 또는 에뮬레이터 (딥링크 테스트용)

🔒 설치 방법

  1. DMG 파일을 다운로드합니다
  2. 다운로드한 파일을 더블클릭하여 마운트합니다
  3. WePray 아이콘을 Applications 폴더로 드래그합니다
  4. 처음 실행 시 macOS 보안 설정에서 "열기"를 클릭합니다

❓ 자주 묻는 질문

Q. 내 Mac이 어떤 칩셋인지 어떻게 확인하나요?

방법 1: 화면 좌측 상단의 메뉴 → "이 Mac에 관하여"를 클릭하면 칩 정보를 확인할 수 있습니다.
방법 2: "Apple M1/M2/M3"라고 표시되면 Apple Silicon, "Intel"이라고 표시되면 Intel 버전을 다운로드하세요.

Q. ADB가 자동으로 설치되나요?

네, WePray는 필요한 ADB 바이너리를 내장하고 있어 별도의 설치 없이 바로 사용할 수 있습니다.

Q. 데이터는 어디에 저장되나요?

모든 딥링크 데이터는 로컬 컴퓨터의 Room 데이터베이스에 안전하게 저장되며, 외부로 전송되지 않습니다.
