## 01. 웹툰 뷰어 네이티브 전환 (BOOKS-1881)
- name: 웹툰 뷰어 네이티브 전환
- project summary: 기존 웹뷰로 보여주던 웹툰을 Android native로 구현하여 네이티브 뷰어로 변경
- develop date: 2022.08.16 ~ 2022.10.07
- 우선순위: 높음
- 개발 내용:
  1. 웹툰 네이티브 뷰어 개발
  2. 웹툰 뷰어 컨트롤러(정주행, 이전/다음화) 네이티브로 개발
  3. 현재 읽은 위치 저장 및 불러오기
  4. 퀵 스크롤 기능 구현
  4. 이미지 리사이징

  1. Glide (이미지 리사이징, 캐싱)
  2. ZoomScrollView(ScrollView 커스텀)
  3. Realm DB (읽은 위치, 웹툰 구매 및 무료 정보 저장)
  4. XML
  5. MVVM
  5. ...
- 겪었던 이슈:
  1. 팀에서 처음에 담당하던 동료가 퇴사하면서 인계받은 업무라서 히스토리 파악이 어려웠음
  2. 커뮤니케이션 히스토리의 중요성을 배워서 개발 설계 문서나 커뮤니케이션 문서를 WIKI에 정리하고 문서화 하였음

## 03. 웹툰 네이티브 뷰어 정주행 이어붙이기 (OST-126)
- name: 웹툰 네이티브 뷰어 정주행 이어붙이기
- project summary: 웹툰 열람시 정주행 기능을 활성화하면 이전/다음화가 뷰어를 벗어나지 않고 다음화일경우 아래, 이전화일경우 위에 붙어서 이어서 볼 수 있도록 한다.
- develop date: 2023.02.01 ~ 2023.06.29
- 우선순위: 높음
- 개발 내용:
  1. 기존에 구현했던 웹툰 네이티브 뷰어를 ScrollView에서 RecyclerView로 구조 개선
  2. Zoom이 가능한 RecyclerView 구현
  3. RecyclerView diffUtil을 사용해서 리스트를 업데이트
  4. 정주행시 이전/다음화가 뷰어를 벗어나지 않고 이어서 볼 수 있도록 개발
  5. 정주행시 이전/다음화가 유료회차일 경우 자동 구매 가능하도록 구현(무료일경우에는 바로보기 가능)
- tech stack:
  1. Glide (이미지 리사이징, 캐싱)
  2. ZoomRecyclerView(Recyclerview 커스텀)
  3. RecyclerView DiffUtil
  4. Realm DB (읽은 위치, 웹툰 구매 및 무료 정보 저장)
  5. Retrofit (네트워크 통신)
  6. XML
  7. MVVM
- 겪었던 이슈:
  1. 기존에 웹툰 뷰어를 네이티브로 개발했던 내용은 만화책 뷰어(Comic 뷰어)에 구현체인 ZoomScrollView를 사용해서 정주행 이어붙이기 기능을 구현했을 시 이전 에피소드가 위에 붙을 때, 깜빡이는 문제가 발생함 이는 ScrollView에서 프로그래밍 방식으로 자식뷰에 새로운 이미지 아이템을 추가할때 인덱스 정보가 변경되면서 UI가 다시 그려져서 발생한 문제
  2. 기존 레거시 코드의 제한적인 문제로 인해 Zoom이 가능한 RecyclerView를 구현하여 웹툰 뷰어의 구조를 전면 개편함
  3. DiffUtil을 사용하여 깜빡이는 문제 해결
  4. 이미 상용에 배포된 시선추적 기능을 새로운 웹툰 뷰어 구조에 문제 없이 이식해야 했기에 사이드 이슈가 발생하지 않도록 테스트 케이스를 다양하게 만들어 해결
